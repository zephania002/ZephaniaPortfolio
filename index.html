About me

I'm a full-stack developer with a B.Sc. in Information Technology from Maseno University. I turn ideas into working software: clear interfaces on the front, reliable APIs and well-designed databases behind them.

My focus is JavaScript, React, Node.js, SQL and MongoDB, plus API work such as M-Pesa payments. I also work in railway operations at Kenya Railways, which shapes how I build: systems that run on schedule and fail safely.

I start with the problem, model the data, then build the smallest version that works and improve it. I'm looking for roles and projects where I can build and ship real systems.
